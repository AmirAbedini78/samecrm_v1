# Task Patterns — الگوهای تکرارشوندهٔ تسک‌ها و تبدیل‌شان به فرایند

تاریخ شروع: 2026-02-17

روش کار:
1) History entry های اخیر را مرور کن.
2) گام‌های تکراری را استخراج کن.
3) اگر عمومی است → به `AI-RULES.md`/`00-GOVERNANCE.md`/shared اضافه کن.
4) اگر مخصوص یک ماژول است → به `smoke_checks` یا `update_rules` همان ماژول اضافه کن.
