# DOC-OPS-LOCAL — گسترش پیشروندهٔ سبک برای مدل‌های لوکال

تاریخ: 2026-02-17

هدف: تکمیل تدریجی داکیومنت در شعاع همان ماژول، با حداقل مصرف کانتکست.

---

## Trigger
بعد از اینکه تغییرات انجام شد و History/ADR آپدیت شد، AI می‌پرسد:
- «این بخش فعلاً تمام/متوقف است؟»

اگر کاربر گفت «بله»:
- Expansion lite اجرا می‌شود.

---

## Expansion Lite Steps (حداکثر 1 آیتم)
AI فقط یکی از این آیتم‌ها را انتخاب می‌کند (بر اساس بیشترین ابهام در memory):
1) Key Files Map (کوتاه: 5–10 فایل)
2) Data/State Notes (کجا ذخیره می‌شود؟)
3) Edge Cases (حداکثر 2 مورد)
4) Testing Notes (چک‌لیست 5 موردی)

سپس:
- 3 سؤال صحت‌سنجی می‌پرسد.
- یک Patch پیشنهادی برای فایل ماژول تولید می‌کند.
- فقط با تأیید کاربر Patch را اعمال می‌کند.
- memory JSON را آپدیت می‌کند.
