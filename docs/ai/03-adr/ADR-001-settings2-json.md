# ADR-001 — ذخیرهٔ تنظیمات تم/فونت به صورت JSON در settings2

تاریخ: 2026-02-17  
وضعیت: Proposed

## Context
تنظیمات ظاهری (فونت/رنگ/…) باید قابل تغییر توسط ادمین باشد و در چند صفحه اعمال شود. نیاز به یک محل پایدار برای ذخیرهٔ این تنظیمات وجود دارد تا هم خواندن/نوشتن ساده باشد و هم توسعهٔ آینده راحت‌تر شود.

## Decision
تنظیمات تم/فونت به صورت JSON در یک کلید مشخص از `settings2` ذخیره شود.

## Alternatives
- ذخیره در فایل‌های ثابت (کمتر قابل مدیریت توسط ادمین)
- جدول جداگانه برای تم (مهاجرت و مدل‌سازی بیشتر)

## Consequences
- اثر مثبت: اضافه/حذف فیلدهای تنظیمات بدون مهاجرت‌های سنگین؛ خواندن سریع تنظیمات در UI.
- ریسک: اگر ساختار JSON بدون نسخه‌بندی تغییر کند، با داده‌های قدیمی ناسازگاری ایجاد می‌شود.
- کار بعدی: اضافه کردن نسخهٔ schema در JSON (اختیاری ولی توصیه‌شده).
