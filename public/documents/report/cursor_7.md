## لاراول چیست؟

لاراول یک فریم‌ورک قدرتمند PHP است که در پروژه CRM شما استفاده شده است. این فریم‌ورک با ویژگی‌های زیر به پروژه شما کمک می‌کند:

### 1. **معماری MVC (Model-View-Controller)**
پروژه شما از ساختار منظم لاراول استفاده می‌کند:
- **Models**: در پوشه `app/Models/` (90 فایل)
- **Controllers**: در پوشه `app/Http/Controllers/` (1090 فایل)
- **Views**: در پوشه `resources/views/` (1019 فایل)

### 2. **پکیج‌های مفید در پروژه شما**
از `composer.json` می‌بینم که پروژه از پکیج‌های مفید زیر استفاده می‌کند:

- **`laravel/framework`**: فریم‌ورک اصلی لاراول
- **`laravel/sanctum`**: برای احراز هویت API
- **`maatwebsite/excel`**: برای کار با فایل‌های Excel
- **`barryvdh/laravel-dompdf`**: برای تولید PDF
- **`intervention/image`**: برای پردازش تصاویر
- **`nwidart/laravel-modules`**: برای ساختار ماژولی

### 3. **مزایای لاراول برای پروژه CRM شما**

#### **توسعه سریع‌تر:**
- سیستم Route خودکار
- Middleware برای امنیت
- Eloquent ORM برای کار با دیتابیس

#### **امنیت:**
- CSRF Protection
- SQL Injection Protection
- XSS Protection
- Authentication System

#### **قابلیت‌های پیشرفته:**
- **Queue System**: برای پردازش پس‌زمینه
- **Event System**: برای مدیریت رویدادها
- **Mail System**: برای ارسال ایمیل
- **Caching**: برای بهبود عملکرد

### 4. **ویژگی‌های خاص پروژه شما**

پروژه شما یک سیستم CRM کامل است که شامل:
- **Reports**: گزارش‌گیری فروش
- **Exports**: صادرات داده‌ها
- **Modules**: سیستم ماژولی
- **RTL Support**: پشتیبانی از زبان‌های راست به چپ
- **Multi-language**: پشتیبانی چندزبانه

### 5. **بهینه‌سازی عملکرد**

لاراول با ویژگی‌های زیر عملکرد پروژه را بهبود می‌بخشد:
- **Autoloader Optimization**
- **Route Caching**
- **View Caching**
- **Config Caching**

## خلاصه Laravel Boost و مزایای آن برای پروژه شما

### **Laravel Boost چیست؟**

**Laravel Boost** یک پکیج جدید است که در **21 اکتبر 2025** به صورت بتا منتشر شده و قابلیت‌های هوش مصنوعی را به محیط توسعه لاراول اضافه می‌کند.

### **ویژگی‌های کلیدی:**

1. **سرور MCP محلی**: یک سرور Model Context Protocol که در محیط محلی شما اجرا می‌شود
2. **دسترسی هوشمند به ابزارها**: 
   - Laravel Tinker
   - پایگاه داده
   - مستندات لاراول
   - لاگ‌های مرورگر
   - ساختار پروژه

### **مزایای Laravel Boost برای پروژه CRM شما:**

#### 1. **تولید کد هوشمند**
- تولید Controllers، Models و Views بر اساس ساختار موجود
- پیشنهاد کدهای بهینه برای ماژول‌های جدید
- تولید Middleware های سفارشی

#### 2. **بهینه‌سازی عملکرد**
- تحلیل Query های کند در دیتابیس
- پیشنهاد Index های مناسب
- بهینه‌سازی Cache ها

#### 3. **تولید تست‌های خودکار**
- Unit Tests برای Models موجود
- Feature Tests برای Controllers
- Integration Tests برای API ها

#### 4. **مدیریت دیتابیس**
- پیشنهاد Migration های بهینه
- تحلیل Schema و روابط
- پیشنهاد Foreign Key ها

#### 5. **رفع باگ‌ها**
- شناسایی مشکلات در کد
- پیشنهاد راه‌حل‌های بهینه
- تحلیل Error Logs
