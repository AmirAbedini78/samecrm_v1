## معرفی پروژه

### زمینه فعالیت
شرکت در حوزه بازرگانی تجهیزات صنعتی و نفتی فعالیت می‌کند و محصولاتی نظیر لوله، بلبرینگ، بیرینگ، بلزونا و مشتقات آن را عرضه می‌کند.

### هدف از پروژه
طراحی و پیاده‌سازی زیرساخت داده‌ای جامع و سیستم CRM برای:
- مدیریت یکپارچه اطلاعات فروش
- مدیریت هوشمند انبار
- گزارش‌گیری و تحلیل داده‌ها
- بهبود فرآیندهای مالی و حسابداری

### فناوری‌های استفاده شده
- **Backend:** Laravel 11 (PHP 8.2)
- **Frontend:** Blade Templates, jQuery, Chart.js
- **Database:** MySQL
- **Infrastructure:** Laragon (محلی) - آماده انتقال به Linux

## خلاصه فعالیت‌ها

### ماه اول: آشنایی و تحلیل
- آشنایی با فرآیندهای شرکت
- نیازسنجی از بخش‌های فروش، مالی و فنی
- تحلیل سیستم‌های موجود
- طراحی معماری راه‌حل

### ماه دوم: توسعه و پیاده‌سازی
فعالیت‌های اصلی در ماه دوم شامل موارد زیر بوده است:

#### 1. پشتیبانی راست‌چین (RTL)
- پیاده‌سازی کامل RTL برای زبان فارسی
- ایجاد فایل CSS اختصاصی (693 خط کد)
- تطبیق تمام کامپوننت‌ها با RTL
- بهبود تجربه کاربری برای استفاده فارسی‌زبانان

#### 2. سیستم انبارداری پیشرفته
سیستم جامعی برای مدیریت انبار طراحی شد که شامل:

**ویژگی‌های کلیدی:**
- مدیریت تراکنش‌های ورود و خروج
- سیستم مدیریت تاریخ انقضا با هشدار خودکار
- دسته‌بندی‌های سفارشی کالاها
- سیستم اعلان (ایمیل و SMS)
- گزارش‌های تحلیلی پیشرفته

**جداول دیتابیس ایجاد شده:**
- `inventory_transactions` (مدیریت تراکنش‌ها)
- `inventory_expiry_dates` (مدیریت تاریخ انقضا)
- `inventory_custom_categories` (دسته‌بندی‌های سفارشی)
- `inventory_alert_settings` (تنظیمات اعلان‌ها)
- `sms_queue` (صف ارسال پیامک)

**قابلیت‌های ویژه:**
- تعیین تاریخ انقضا خودکار در صورت عدم تعیین توسط کاربر
- تغییر رنگ خودکار برای کالاهای نزدیک به انقضا
- اعلان‌های ایمیل و SMS برای موارد بحرانی
- فیلتر هوشمند بر اساس وضعیت (منقضی شده، نزدیک به انقضا، عادی)

#### 3. گزارش‌گیری فروش پیشرفته

**الف) گزارش مقایسه بازه‌های تاریخی:**
- مقایسه دو بازه زمانی مختلف
- دو DataTable پیشرفته با قابلیت‌های:
  - جستجوی پیشرفته در هر ستون
  - مرتب‌سازی (Sort)
  - تنظیم نمایش/مخفی کردن ستون‌ها
  - فیلتر پیشرفته
  - Export داده‌ها

**ب) تحلیل‌های فروش و نمودارها:**
سیستم جامع تحلیل داده‌ها با 5 تب اصلی:

1. **تحلیل زمانی:**
   - نمودار روند فروش ماهانه
   - نمودار مقایسه فصلی
   - نمودار مقایسه سال به سال

2. **تحلیل محصولات:**
   - Top 10 محصولات پرفروش
   - نمودار سهم هر محصول از کل فروش
   - تحلیل مقدار فروش هر محصول

3. **تحلیل مشتریان:**
   - نمودار مشتریان برتر (قانون 80/20)
   - تحلیل تجمعی درصد مشتریان
   - نمودار روند خرید هر مشتری

4. **تحلیل مالی:**
   - نمودار سود ناخالص
   - تحلیل میانگین مبلغ فاکتور
   - تحلیل نرخ تخفیف

5. **تحلیل لجستیک:**
   - درصد سفارشات تحویل نشده
   - زمان تحویل در مقابل مشتری

**ویژگی‌های پیشرفته:**
- فیلتر پیشرفته بر اساس تاریخ، محصول، مشتری، انبار
- دو روش فیلتر زمانی (سال/ماه و تاریخ دقیق)
- نمایش خلاصه تمرکز (Focus Summary) برای فیلترهای اعمال شده
- استفاده از Chart.js برای نمودارهای تعاملی
- جلوگیری از نمایش داده‌های NaN
- فرمت خوانا برای اعداد و درصدها

#### 4. دسته‌بندی مشتریان
- ایجاد سیستم دسته‌بندی مشتریان بر اساس فایل XML
- اضافه کردن فیلتر دسته‌بندی در گزارش‌ها
- پیاده‌سازی Cascading Dropdown (انتخاب دسته → فیلتر مشتریان)

#### 5. ماژول فاکتور و تسویه
- ایجاد زیرمنوی جدید در بخش حسابداری
- طراحی کامل CRUD برای فاکتور و تسویه
- DataTable پیشرفته مشابه بخش فروش
- قابلیت Import از Excel
- Migration، Model، Controller و Repository

#### 6. بهبودهای UI/UX
- اصلاح رنگ‌بندی گزارش انبار برای راحتی چشم
- بهبود خوانایی داده‌ها در جداول
- بهینه‌سازی نمایش نمودارها
- اضافه کردن Progress Bar و Loading States

#### 7. راه‌اندازی شبکه شرکت
- تنظیم پروژه برای دسترسی از شبکه شرکت
- پیکربندی Apache و Firewall
- تست دسترسی از کامپیوترهای مختلف شبکه

#### 8. اصلاحات و Bug Fixes
- حذف محاسبه میانگین از گزارشات (طبق درخواست)
- اصلاح مسیرهای JavaScript برای بارگذاری داده‌ها
- رفع مشکلات Syntax Error در Middleware
- بهبود منطق نمایش داده‌ها

## دستاوردهای کلیدی

### 1. سیستم انبار هوشمند
سیستمی که فراتر از مدیریت ساده موجودی است:
- **پیش‌بینی خودکار:** سیستم به صورت خودکار تاریخ انقضا را پیش‌بینی می‌کند
- **هشدار هوشمند:** اعلان‌های خودکار برای کالاهای بحرانی
- **مدیریت یکپارچه:** یکپارچه با بخش فروش و مالی

**ارزش افزوده:**
- کاهش ریسک نگهداری کالاهای منقضی شده
- صرفه‌جویی در زمان مدیریت انبار
- بهبود تصمیم‌گیری در مورد سفارشات

### 2. گزارش‌گیری تحلیلی پیشرفته
سیستمی که داده‌های خام را به بینش عملی تبدیل می‌کند:
- **تحلیل چندبعدی:** از جنبه‌های زمانی، محصولی، مشتری، مالی و لجستیک
- **قابلیت مقایسه:** مقایسه بازه‌های زمانی مختلف
- **نمایش بصری:** نمودارهای تعاملی و خوانا

**ارزش افزوده:**
- شناسایی روندهای فروش
- شناسایی محصولات و مشتریان برتر
- کمک به تصمیم‌گیری استراتژیک

### 3. پشتیبانی کامل فارسی
- تمام بخش‌ها کاملاً راست‌چین شده‌اند
- تجربه کاربری مناسب برای کاربران فارسی‌زبان
- پشتیبانی از تاریخ شمسی

### 4. معماری قابل توسعه
- کد تمیز و ساختاریافته
- استفاده از Repository Pattern
- Middleware برای مدیریت دسترسی‌ها
- آماده برای افزودن ویژگی‌های جدید

## نتیجه‌گیری

در طی دو ماه گذشته، با موفقیت زیرساخت داده‌ای جامع و سیستم CRM برای شرکت طراحی و پیاده‌سازی شده است. این سیستم نه تنها نیازهای فعلی شرکت را برآورده می‌کند، بلکه آماده برای گسترش و افزودن ویژگی‌های جدید در آینده است.
